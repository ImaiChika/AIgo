# 年度大纲与知识点管理

年度变化以整套大纲版本承载。知识点条目的修订号用于并发编辑校验，和大纲版本、题目版本分别管理。

## 日常操作

1. 在知识点页点击“新建版本”，填写考试年份、版本名称和说明。
2. 在新版本中批量导入文件，或选择左侧目录后新增知识点。表单会带入所选目录。
3. 整理完成后“启用此版本”。默认版本按考试年份降序排列，同年按创建时间降序排列；未启用版本不会影响默认出题大纲。
4. 左上角显示当前版本。点击右侧“切换 / 管理版本”，打开独立窗口；按年份、名称或说明搜索，也可筛选已启用/整理中，选中版本并确认后切换。取消不会改变当前工作版本。
5. 管理员可在该窗口删除任意整套版本。确认页展示版本名称、知识点数量及默认大纲回退结果。已有题目、审核记录及已提交批量任务保持原有快照。

删除默认大纲后，默认版本回退到剩余年份最新的已启用大纲；没有已启用大纲时，出题选择器显示空状态。管理页可继续整理草稿；删空后仍可新建版本。删除后的名称可重新使用，新版本会获得全新 ID。其他浏览器标签页在收到版本变更通知或重新获得焦点时刷新版本列表，清理已经失效的知识点选择。

知识点页点击左侧任意层级，右侧包含该目录下的全部知识点。关键词搜索和分页保持当前目录及版本。出题页和批量页保留原选择器布局，切换版本会清空已选知识点。

## 文档导入

支持一次上传 1–20 个文件，总大小不超过 32 MB，最多 50,000 条知识点：

- `.xlsx`：读取全部工作表，支持目录列合并/留空后向下延续。
- `.csv`：UTF-8 编码，可在页面下载模板。
- `.docx`：读取有表头的普通大纲表格；不支持嵌套表格、扫描件或自动提取自由文本中的医学知识点。

表头：`分类、专业/系统、单元、细目、要点、大纲代码、关键词`。关键词可省略；单元、细目可留空。列序可变；兼容原大纲中的“序号”列。分类和专业不能为空。目录父级变化时，不继承上一父级的子目录。原始大纲中无内容、目录标为“暂存”且代码以 `.0` 结尾的预留行跳过。

“追加 / 更新”按当前版本的大纲代码匹配，重复内容跳过，变化内容更新。“替换此版本整套大纲”以本批文件为完整集合，删除本版本中未出现在文件里的知识点。不同文件中相同代码、不同内容会报冲突。全部文件校验通过后在同一个数据库事务内提交；任何错误都不留下部分导入结果。

同版本单条新增不覆盖已有代码，而是返回冲突。编辑时提交修订号，过期的编辑返回 409，刷新数据后再修改。

## 数据兼容与迁移

新增数据库迁移 **4 / knowledge_syllabus_versions** 和 **5 / knowledge_version_deletion**，历史迁移及 `schema.sql` 基线不改写。迁移 5 增加版本软删除和有效版本名称唯一约束。整套删除与导入、修改、启用共用事务锁，过期请求无法恢复已删除版本。部署前执行：

```sh
go run ./cmd/aigo migrate
```

已有知识点归入“历史大纲（年份待确认）”，保留原 ID 和内容，不推断其年份。新版本使用独立 ID，代码在同一版本的有效知识点中唯一。删除使用软删除。题目原有 JSON 知识点快照保留；新增题目保存版本 ID、名称、年份、知识点修订号和内容。

批量任务提交保存知识点快照，结果导入优先使用该快照；不再使用当时的默认大纲覆盖提交上下文。缺失快照或无法匹配的结果会报错。历史任务兼容大纲代码作为 provider custom_id；新增年度任务使用跨版本唯一的知识点 ID。无大纲代码的手动知识点也使用 ID。

API 查询未指定 `version_id` 时只查默认版本，没有默认版本时返回正常空列表；显式指定不存在或已删除的版本返回 404，不能静默改用其他版本。`DELETE /api/knowledge-versions/{id}` 需要 `knowledge:manage` 权限，删除整个版本并记录审计。单题请求传 `knowledge_point_id`、`version_id`，批量请求传 `knowledge_point_ids`、`version_id`。旧请求只传 `outline_code` 时在默认版本内精确匹配，不再把找不到的代码静默当成临时知识点。自由主题生成（未传知识点 ID、代码和版本）仍兼容现有接口。

知识点服务默认统计和列表均限定最新版本；存储层仍提供全部版本读取，供维护用途。审核、题库及导出使用题目自己的内容快照，不依赖当前知识点表。

## 验证

```sh
go test ./...
AIGO_TEST_POSTGRES_DSN='postgresql:///postgres?host=/tmp&sslmode=disable' go test ./internal/storage/postgres ./internal/api ./internal/review ./internal/auth
cd web && npm run build
```

PostgreSQL 集成测试会创建并清理独立 schema。新增回归覆盖年度隔离、默认版本、事务回滚、整套替换、并发编辑、关键词更新、代码冲突、树过滤、权限、Word 表格解析和批量任务快照恢复；整套删除新增失败回滚、并发导入防恢复、默认回退、无默认版本空响应及只读权限回归。

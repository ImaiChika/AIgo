数据库表（PostgreSQL）
====================

users                # 用户表（账号、密码哈希、角色、昵称）
knowledge_points     # 知识点表（科目、系统、名称、关键词）
questions            # 题目表（题干、选项、答案、解析、状态、版本）
experts              # 专家表（姓名、科室、职称、擅长知识点）
review_flows         # 审核流程配置表（流程名、轮次配置JSON）
review_tasks         # 审核任务表（题目ID、流程ID、当前轮次、状态）
review_records       # 审核记录表（任务ID、轮次、审核人、结论、意见）
batch_jobs           # 批量任务表（任务名、状态、进度、知识点JSON）
ai_review_results    # AI检查结果表（verdict、四维评分、问题列表、建议）


API 接口
========

认证:
  POST   /api/auth/login              登录（返回JWT）
  GET    /api/auth/me                 当前用户信息
  PUT    /api/auth/profile            修改昵称
  POST   /api/auth/change-password    修改密码

用户管理（仅管理员）:
  GET    /api/users                   用户列表
  POST   /api/users                   创建用户

题目:
  POST   /api/questions/generate      生成题目（调千问）
  GET    /api/questions               题目列表
  GET    /api/questions/search?q=     搜索题目
  GET    /api/questions/{id}          题目详情
  PUT    /api/questions/{id}          修改题目
  DELETE /api/questions/{id}          删除题目

知识点:
  GET    /api/knowledge-points        知识点列表
  GET    /api/knowledge-points/search 搜索知识点
  POST   /api/knowledge-points/import Excel导入
  DELETE /api/knowledge-points/{id}   删除知识点

专家:
  GET    /api/experts                 专家列表
  POST   /api/experts                 创建专家
  PUT    /api/experts/{id}            修改专家
  DELETE /api/experts/{id}            删除专家

AI检查:
  POST   /api/ai-check                批量AI检查题目
  GET    /api/ai-check/result/{id}    单题检查结果
  GET    /api/ai-check/results        所有检查结果

批量推理:
  POST   /api/batch/submit            提交批量任务
  GET    /api/batch/list              任务列表
  GET    /api/batch/status/{jobId}    任务状态
  POST   /api/batch/download/{jobId}  下载结果并导入

审核:
  POST   /api/review/submit           提交审核
  POST   /api/review/action           审核操作
  GET    /api/review/task/{id}        审核任务详情
  GET    /api/review/task-by-question/{id}  按题目查审核任务
  GET    /api/review/records/{id}     审核记录
  GET    /api/review/flows            审核流程列表

导出:
  POST   /api/export/xlsx             导出Excel
  POST   /api/export/docx             导出Word
  GET    /api/export/download/{file}  下载导出文件

统计:
  GET    /api/stats                   系统统计


角色权限
========

admin（管理员）:  全部权限
expert（专家）:   出题、知识点增删、题库删除、审核、专家查看
teacher（教师）:  出题、知识点查看、AI检查、提交审核

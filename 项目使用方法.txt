AIgo 项目使用方法
=================

说明：
本项目当前包含 Go 后端框架和 Vue 3 + Vite 前端原型。
当前前端仍是可交互原型，尚未接入真实后端 API、真实千问出题接口和真实生图模型。


一、进入项目目录
----------------

项目根目录：

/Users/imaichika/Documents/AIgo

进入项目：

cd /Users/imaichika/Documents/AIgo


二、必须先阅读的文件
--------------------

后续开发前建议先阅读：

1. 功能需求文档.txt
2. CLAUDE.md
3. 当前还缺的功能提示.txt

其中：
- 功能需求文档.txt 是当前产品需求基准。
- CLAUDE.md 是给 Claude Code 或后续开发模型看的开发约束。
- 当前还缺的功能提示.txt 记录目前还没完成的关键功能。


三、Go 后端检查
---------------

当前 Go 后端主要是框架、领域模型、知识点导入、审核流程、图片候选等模块。

运行测试：

go test ./...

运行 CLI 自检：

go run ./cmd/aigo doctor

运行示例评估：

go run ./cmd/aigo evaluate


四、千问 API 环境变量
--------------------

调用真实千问接口前，需要设置环境变量：

export DASHSCOPE_API_KEY="你的阿里云百炼 API Key"
export QWEN_BASE_URL="https://dashscope.aliyuncs.com/compatible-mode/v1"
export QWEN_MODEL="qwen-plus"

注意：
- 不要把真实 API Key 写进代码。
- 不要把真实 API Key 提交到仓库。


五、Vue 3 + Vite 前端原型
------------------------

前端目录：

web/

进入前端目录：

cd /Users/imaichika/Documents/AIgo/web

首次运行前安装依赖：

npm install

启动开发服务器：

npm run dev -- --port 5174

浏览器访问：

http://127.0.0.1:5174

构建前端：

npm run build


六、当前前端已包含的内容
----------------------

前端原型已经包含：

- 左侧后台导航。
- AI 出题工作台。
- 知识点标签。
- 题干编辑。
- 选项编辑。
- AI 配图候选。
- 结构化生图提示词。
- 右侧 AI 出题配置。
- 实时预览。
- 审核流状态。
- 保存草稿、提交审核等模拟交互。


七、当前还没有接入的内容
----------------------

当前还没有完成：

- Go 后端 HTTP API。
- 前端调用后端 API。
- 真实千问出题。
- 真实 AI 生图模型。
- Excel 知识点上传页面与接口。
- 数据库落库。
- 专家库完整页面。
- 多轮审核完整页面。
- 图片审核页面。
- 题库查询和导出页面。
- 登录和权限控制。


八、当前不要优先做的内容
----------------------

根据最新需求，当前不要优先做：

- 知识图谱。
- Neo4j。
- 混淆网络。
- IRT 或深度 IRT。
- Bloom 分类。
- 强化学习优化。
- 医学模型微调。
- 复杂来源资料管理。
- 历史真题强依赖。
- 把解析或试题来源做成必填。


九、关闭前端开发服务器
----------------------

如果前端服务器正在运行，在对应终端按：

Ctrl + C

如果端口被占用，可查看进程：

lsof -nP -iTCP:5174 -sTCP:LISTEN

然后结束对应进程。


十、建议开发顺序
----------------

1. 做 Go HTTP 服务。
2. 做知识点 Excel 上传和搜索 API。
3. 接前端知识点真实数据。
4. 接千问真实出题 API。
5. 做题目保存和查询。
6. 接 AI 生图候选图流程。
7. 做专家库。
8. 做多轮审核流程。
9. 做图片审核。
10. 做题库导出。

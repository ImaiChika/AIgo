AIgo 项目使用方法
=================

说明：
本项目包含 Go 后端 + Vue 3 前端 + PostgreSQL 数据库。
默认管理员：admin / admin（仅演示库；新库首次启动时密码随机生成并由启动日志打印，或由 AIGO_ADMIN_PASSWORD 指定）


一、环境要求
------------

- Go 1.26+
- Node.js 18+
- PostgreSQL 16+
- 阿里云百炼 API Key


二、首次启动
------------

1. 启动 PostgreSQL：

   brew services start postgresql@16

2. 创建数据库：

   createdb aigo

3. 配置环境变量：

   cp configs/example.env .env
   # 编辑 .env，填入：
   # DASHSCOPE_API_KEY=你的API Key
   # QWEN_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
   # QWEN_MODEL=qwen3.6-flash
   # DB_DSN=postgres://localhost:5432/aigo?sslmode=disable

4. 启动后端：

   go run ./cmd/aigo serve

   首次启动会自动建表和创建默认管理员。

5. 启动前端（另一个终端）：

   cd web
   npm install
   npm run dev -- --port 5174

6. 浏览器访问：

   http://127.0.0.1:5174

   登录：admin / admin（演示库）；新库见启动日志打印的管理员密码


三、导入数据
------------

导入知识点：

  go run ./cmd/aigo kp-import 知识点表.xlsx

导入题目：

  go run ./cmd/aigo import 2025执医A2.xlsx

或通过前端页面上传。


四、关闭服务
------------

  # 停止后端（Ctrl+C 或）
  pkill -f "aigo serve"

  # 停止前端（Ctrl+C 或）
  pkill -f "vite"

  # 停止 PostgreSQL
  brew services stop postgresql@16


五、CLI 命令
------------

  go run ./cmd/aigo doctor              检查框架状态
  go run ./cmd/aigo serve               启动 HTTP 服务（默认 8080 端口）
  go run ./cmd/aigo serve 3000          指定端口启动
  go run ./cmd/aigo import <file.xlsx>  导入题目
  go run ./cmd/aigo kp-import <file.xlsx> 导入知识点
  go run ./cmd/aigo kp-list             列出知识点
  go run ./cmd/aigo kp-search <关键词>  搜索知识点
  go run ./cmd/aigo list                列出题目
  go run ./cmd/aigo generate            调 API 生成新题（需 Key）


六、前端页面
------------

  /login          登录页
  /generate       AI出题（选知识点 → 生成 → 编辑 → 保存 → 配图）
  /knowledge      知识点管理（搜索、添加、删除、Excel导入）
  /review         多轮审核（选题 → 提交审核 → 审核 → 记录）
  /bank           题库（搜索、筛选、详情、编辑、删除、发布、导出）
  /experts        专家库（增删改查，仅管理员）
  /review-flows   审核流程配置（仅管理员）
  /audit          操作日志（仅管理员）
  /users          用户管理（仅管理员）


七、API 接口
------------

  POST   /api/auth/login              登录
  GET    /api/auth/me                 当前用户
  GET    /api/stats                   统计

  POST   /api/questions/generate      生成题目
  GET    /api/questions               题目列表
  GET    /api/questions/search?q=     搜索题目
  GET    /api/questions/{id}          题目详情
  PUT    /api/questions/{id}          修改题目
  DELETE /api/questions/{id}          删除题目
  POST   /api/questions/{id}/publish  发布题目

  GET    /api/knowledge-points        知识点列表
  GET    /api/knowledge-points/search 搜索知识点
  POST   /api/knowledge-points        创建知识点
  POST   /api/knowledge-points/import Excel导入
  DELETE /api/knowledge-points/{id}   删除知识点

  GET    /api/experts                 专家列表
  POST   /api/experts                 创建专家
  PUT    /api/experts/{id}            修改专家
  DELETE /api/experts/{id}            删除专家

  GET    /api/review/flows            审核流程列表
  POST   /api/review/flows            创建审核流程
  POST   /api/review/submit           提交审核
  POST   /api/review/action           审核操作
  GET    /api/review/task/{id}        审核任务
  GET    /api/review/records/{id}     审核记录

  GET    /api/audit-logs              操作日志
  GET    /api/users                   用户列表
  POST   /api/users                   创建用户
